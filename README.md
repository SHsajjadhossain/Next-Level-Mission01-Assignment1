# TypeScript Assignment

## Assignment Overview

This assignment is about practicing TypeScript concepts from Modules 1, 2, and 3. The coding solutions are written in one file named 'solutions.ts'.

### Problem Solving

The 'solutions.ts' file contains solutions for these 8 problems:

1. **multiplyValue** – A function with an optional multiplier. If no multiplier is given, it multiplies the value by 2.
2. **processInput** – A function that handles string, number, and boolean values using type narrowing.
3. **formatCoordinate** – A function that formats a coordinate using a readonly tuple.
4. **concatenateArrays** – A generic function that combines multiple arrays of the same type.
5. **getPopularCourses** – An interface and a function that filters published courses based on the minimum number of students.
6. **pluckValues** – A generic function that gets the values of a selected property from an array of objects.
7. **Employee and Manager** – Classes that show inheritance and the use of 'protected' and 'private' access modifiers.
8. **validateAgeAsync** – An asynchronous function that returns a Promise and checks the given age.
